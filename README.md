
# ShopEasy - E-Commerce Store

A modern e-commerce web application built with React and Vite.

## Features
- Browse products fetched from an API
- Search for products
- Add products to the shopping cart
- Increase or decrease product quantities
- Remove products from the cart
- Calculate the total price
- Save cart items using localStorage
- Navigate between pages using React Router
- Responsive user interface

## Technologies Used
- React
- JavaScript
- CSS
- React Router
- Fake Store API
- Vite

## Run Locally

1. Clone this repository.
2. Install dependencies:

   `npm install`

3. Start the development server:

   `npm run dev`

## Project
Built as a learning project to practice React components, hooks, routing, API integration, and cart state management.
